Export SeLoger

Un favori de navigateur qui exporte en CSV les clients d'une page annuaire SeLoger (nom, type, nb d'annonces vente/location, adresse, SIRET, lien fiche pro) — sans rien installer. Il tourne dans ta session déjà connectée, pas dans un outil séparé.

🗂️ Export SeLoger ⟵ glisse ce bouton dans ta barre de favoris

Installation (une fois)

  1. 1 Affiche ta barre de favoris

    Si elle n'est pas visible : Ctrl/Cmd + Maj + B dans Chrome, Edge ou Firefox.
  2. 2 Glisse le bouton "🗂️ Export SeLoger" ci-dessus dans la barre

    Un nouveau favori apparaît. Tu peux le renommer si tu veux.
  3. 3 Le glisser-déposer ne fonctionne pas ?

    Clique "Copier le code du favori", puis dans ta barre de favoris : clic droit → Ajouter une page (ou Nouveau favori) → mets un nom (ex: "Export SeLoger") et colle le code copié dans le champ URL/adresse.

À chaque export

  1. 1 Va sur la page annuaire du département sur seloger.com

    Ex : seloger.com/annuaire/indre-et-loire-37/
  2. 2 Clique sur le favori "🗂️ Export SeLoger"

    Un petit panneau apparaît en haut à droite de la page.
  3. 3 Choisis les pages, clique "Lancer"

    Laisse l'onglet ouvert pendant l'export — ferme le panneau ou change de page l'arrête.
  4. 4 Clique "Télécharger le CSV"

    Le fichier s'ouvre directement dans Excel (colonnes déjà séparées).

⚠️ À lire avant de lancer un gros export

  • SeLoger détecte et bloque temporairement les comportements de scraping trop rapides ou trop volumineux (message "Accès temporairement restreint"). Un blocage touche la connexion de la personne qui l'a déclenché, pas les autres.
  • Découpe les gros départements en tranches (ex: pages 1-15, pause, puis 16-30) plutôt qu'un export complet d'un coup, surtout pour Paris ou les grandes villes.
  • Si un message de blocage apparaît : arrête, attends quelques heures avant de réessayer sur seloger.com (même en navigation normale). Insister prolonge le blocage.
  • Un seul export à la fois par personne — ne lance pas plusieurs favoris en parallèle sur plusieurs onglets.

Détails techniques

Le favori lit le JSON déjà présent dans la page (le même que SeLoger utilise pour afficher l'annuaire), tourne page par page avec des délais entre chaque fiche, et génère le CSV directement dans ton navigateur — aucune donnée n'est envoyée à un serveur externe. C'est la même logique que le script Python scrape_seloger.py du dépôt, adaptée pour tourner sans installation dans un navigateur verrouillé.

Un souci technique ou un champ qui sort vide/faux ? Remonte-le avec le nom du département et une copie du message affiché dans le panneau.
